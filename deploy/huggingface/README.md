# Sila — SME Liquidity Mesh

Live demo of [github.com/Ayshalubna/sila](https://github.com/Ayshalubna/sila).
Sila forecasts every small business's cash four weeks ahead and closes gaps by changing when existing invoices
between network members are paid: no loans, no interest, nothing without both owners' consent.
English and Arabic. All data is synthetic.
